# Apple MCP Core Implementation Plan

**Goal:** Read Apple account data and safely plan/apply version-localization metadata edits.
**Architecture:** stdio MCP → typed service → Apple HTTP client; SQLite plan journal; CLI execution.
**Tech Stack:** Node >=24, TypeScript, MCP SDK 2, Zod, node:sqlite.
**Spec:** ../specs/2026-11-07-apple-mcp-design.md

## Global constraints
No secret output; read-only default; app write allowlist; no live account mutation during development.

## Review focus
Credential host leakage; truncated pagination; expired/stale plans; uncertain PATCH outcomes;
concurrent plan execution. Cover each in tests for the owning module.

## Tasks
- [x] Configuration/auth/client: src/config.ts, src/apple.ts; strict config, ES256 JWT,
  timeout and bounded read retries, validated pagination, tests in test/apple.test.ts.
- [x] Plan journal/service: src/plans.ts, src/service.ts; create/get/claim/release plans,
  metadata preparation, remote conflict detection and reconciliation; test/plans.test.ts.
- [x] MCP/CLI: src/server.ts, src/cli.ts; register typed tools, expose explicit apply command,
  verify handshake and schema enforcement in test/server.test.ts.
- [x] README, example config, CI; run npm run check, npm test, npm run build.
